# Upwork Clone

A fully responsive Upwork-inspired website built using HTML and CSS. The project focuses on recreating a modern freelancing platform interface with responsive layouts and mobile-friendly navigation.

##  Features

- Fully responsive design
- Desktop, tablet, and mobile layouts
- Mobile-friendly hamburger menu
- Responsive navigation
- Modern and clean UI
- Responsive sections and components
- CSS Media Queries for different screen sizes
- Structured HTML5 markup
- Custom CSS styling

##  Responsive Design

The website is designed to work smoothly across:

-  Desktop
-  Mobile
-  Tablet

Media queries are used to adjust the layout, navigation, spacing, typography, and other UI elements according to the screen size.

##  Technologies Used

- HTML5
- CSS3
- CSS Media Queries
- Responsive Web Design
